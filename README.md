# Sub-Saharan Africa Agricultural & Food Security Risk Analysis (2000–2024)

## Project Overview
This repository contains a longitudinal analysis of Sub-Saharan African agricultural metrics (Area harvested, Yield, and Production volume) using FAOSTAT data from 2000 to 2024. The project evaluates multi-year structural trends to identify food security risks across regions and key staple crops.

## Repository Contents & Links
* [Interactive Google Sheets Workbook](https://docs.google.com/spreadsheets/d/1ZGaKBGF8fNteHcCBb_oN8qDymXqEJH23r4if3j6zGEc/edit?usp=sharing): Features the raw data tab, cleaning log, aggregated pivot tables, and interactive dashboard tab with 2000–2024 trend line charts and risk summary table.
* **Sub_Saharan_Africa_Food_Security_Risk_Summary.docx**: The 1-page written analysis report containing methodology, regional breakdowns, and risk rationales (uploaded in this repository).

## Key Findings & Risk RankingWestern Africa (Fresh Cassava) — Critical Risk:k:** Moderate yield contraction (-20.05%) paired with a massive baseline production volume (~79M tonnes annually) threatens regional caloric stability.Southern Africa (Sorghum & Millet) — High Risk:k:** Severe, multi-year yield declines (-47.11% for Sorghum and -79.79% for Millet) highlight acute climate and soil vulnerability.Eastern & Middle Africa (Maize, Rice) — Low Risk / Stable Growth:h:** Demonstrates positive, sustained productivity growth offsetting regional pressures.
